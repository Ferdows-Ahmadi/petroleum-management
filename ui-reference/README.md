# Petroleum Wholesale Management UI Prototype

Static Dari/RTL UI prototype for the Laravel petroleum management system.

## Preview
Open `login.html` or `dashboard.html` in a browser. Internet access is only used for the Vazirmatn font and Bootstrap Icons CDN.

## Important
- This is a UI prototype, not the final Laravel application.
- All displayed people/companies are fictional/anonymized.
- Values are demonstration values.
- The layout is Dari-first and RTL-first.
- Codex should convert this design into Blade layouts/components without redesigning the information architecture.
